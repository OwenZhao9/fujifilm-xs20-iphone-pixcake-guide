# 本次调试记录

本记录按实际提问与反馈整理。“确认”表示收到用户明确反馈；“资料步骤”表示核对了文档，但没有该环节的实机成功反馈。原始设备照片和完整聊天记录未作为附件公开。

## 目标与已知条件

- 在户外，富士 X-S20 连接自己的 iPhone，使用像素蛋糕接收照片。
- 拍摄用途是给游客交付高质量大图，不要求保存全部拍摄原始数据。
- 相机模式转盘为 A，图像质量为 FINE，用户看到的尺寸选项为 L/M/S。
- 未记录具体 iPhone 型号、相机固件版本及像素蛋糕版本。固件就是相机内部运行的程序，像手机系统一样，版本变化可能改变菜单或连接行为；本次版本缺失，影响他人复现判断。

## 这次调试能复用什么

最明确的经验是：**遇到网络菜单灰色，先检查当前连接模式；临时切 USB读卡器后再配置网络，在本次设备上起效。**

另一个可复用的操作是：密码键盘里，MENU/OK 确认的是光标所在项目；提交密码要先选 SET。网络登记后，某些菜单版本还必须确认“结束”保存，再选择配置启用。

不能由此推断所有灰色菜单都来自同一个原因，也不能把“入口恢复可选”当作“所有照片已成功保存”。本次没有确认无线完整传图、有线成功、手机系统相册导出、双份保存、逐字节无损或速度比较。

## 对早期解释的澄清

- 教程以用户屏幕上的 L/M/S 表示尺寸；说明书中的符号不适合直接拿来当菜单搜索目标。
- “电源关/通信开”指连接供电设置，不是机身关机；禁止相机向连接设备取电，不能保证阻止相机反向给手机充电。
- FINE 是高质量成片，并不等于保留全部原始数据。大图也不自动等于无损。
- 无线固定联机按没有卡内备份对待；接收文件是否完成、是否还在相机缓冲中，应实机检查，不能假定每次断线都有安全副本。

## 读者反馈时建议提供

手机型号、系统版本、相机内部程序版本、软件版本、线材与接口、当前连接模式、供电设置、哪个菜单灰色或哪一步断开，以及单张是否完整收到。分享屏幕照片时遮住热点密码、个人网络名称和不需要公开的信息。

这些信息有助于把“同样连不上”拆成具体问题，例如菜单入口受限、热点未加入、手机只充电，或软件已连接但文件没导入。新反馈应说明执行了什么、结果是什么，不直接写成未经验证的通用结论。
