## 补充相机设置资料

- [Evoto 的富士无线设置](https://support.evoto.ai/wireless-tethered-shooting-with-evoto-fuji-film/)：Evoto 是另一个修图软件，像素蛋糕仍是本教程使用的软件；只参考其对相机菜单的操作说明。它建议网络设置灰色时临时切 USB 读卡器，本次 X-S20 用户确认这个操作恢复了网络菜单。
- [Capture One 的富士无线指南](https://support.captureone.com/hc/en-us/articles/10873615954461-FUJIFILM-wireless-tethering-guide)：Capture One 也是接收和处理相机照片的软件，这里用它的 X-S20 专门说明交叉检查卡内保存限制；不能把该软件的其他功能当作像素蛋糕功能。
