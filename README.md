# 富士 X-S20 连接 iPhone：像素蛋糕户外拍摄教程

给游客拍照时，怎样让相机拍完的照片直接进入手机，供查看、修图和交付？这份教程整理了富士 X-S20 连接 iPhone 的无线、有线方法，以及一次实际设置过程中遇到的问题。

像素蛋糕是手机修图软件；连接相机后，它能接收新拍的照片，像把手机变成随身看图和修图的工作台。本教程的无线方案使用 **iPhone 自己的个人热点**，在户外不需要额外的路由器。

整理日期：2026-10-08。相机菜单和软件按钮可能随版本变化，以设备实际显示为准。本文为经验整理，非厂商官方教程。

## 连接前准备

1. 相机装好存储卡，手机和相机都有足够电量、可用空间。即使某种联机模式不把照片写入卡，像素蛋糕仍要求机内安装存储卡。
2. 相机处在照片拍摄模式。本次使用 **A 档**，即由你选择光圈、相机配合决定快门速度；它可以用于拍照片，不必仅为连接改档。
3. 在像素蛋糕请求相机访问权限时允许；有线方式还需要文件访问权限。
4. 为避免相机休眠导致断开，可把相机「设置 → 电源管理 → 自动关机」暂设为「关」，拍摄结束后恢复日常设置。

[像素蛋糕准备要求](https://www.pixcakeai.com/guide/97407)、[富士电源管理说明](https://app.fujifilm-dsc.com/zhs/manual/x-s20/connections/network_usb_menu/)

## 无线连接：户外使用 iPhone 个人热点

个人热点可以让相机和手机通过无线连接交换文件，像在两台设备间搭一座桥。**相机传到这部手机的照片走本地连接；手机软件另外上网是另一回事。**[流量问答](docs/FAQ.md#传照片会消耗手机流量吗)

### 第一步：开启手机热点

在 iPhone「设置 → 个人热点」打开「允许其他人加入」，记住热点名称和密码。首次连接时，暂时停留在这个设置页面，方便相机发现热点。

如果相机搜不到热点，且手机提供「最大兼容性」，可尝试打开后重新搜索；这可能降低无线速度，因此作为连接排查手段使用。[苹果说明](https://support.apple.com/zh-cn/111785)

### 第二步：让相机登记这个热点

先拔掉相机数据线。进入：

**MENU/OK → 网络/USB设置 → 网络设置**

如果「网络设置」是灰色，先把「连接模式」临时改成 **USB读卡器**，再回到「网络设置」。这里的读卡器模式用于解除本次遇到的菜单限制；后面还要切回无线联机模式。这一步在本次 X-S20 上恢复了网络设置的可选状态。[灰色菜单问答](docs/FAQ.md#网络设置是灰色的怎么办)

随后进入「接入点设置 → 手动设置 → 从网络列表中选择」，选自己的 iPhone 热点并输入密码。接入点就是相机要加入的无线网络，在这里就是手机热点。

有些版本会先让你选一个无线网络配置编号，例如「1」，再进入接入点设置。配置编号像保存好的通讯录条目，方便下次直接使用。

### 第三步：确认密码，保存并启用网络

**输入完密码后，先用相机背面的小摇杆把光标移到屏幕键盘的「SET／设定」，再按 MENU/OK。**

光标还在字母上时，MENU/OK 的作用是输入那个字母，不是提交整段密码。如果多输入了字符，先删除再提交。[富士密码输入说明](https://app.fujifilm-dsc.com/en/tether/tether_wireless.html)

显示登记完成后按 MENU/OK。如果回到无线网络配置页面，还能看到「结束／FINISH」，要选择它并确认，保存配置。然后选刚保存的网络条目 → MENU/OK →「选择／SELECT」。较旧菜单没有这层页面时，按实际完成提示退出即可。[像素蛋糕保存网络教程](https://www.pixcakeai.com/guide/170683)

### 第四步：切到无线联机模式

进入「网络/USB设置 → 连接模式」，选择 **无线 TETHER拍摄固定**。TETHER 是菜单里“联机拍摄”的英文：让外部设备接收、参与控制拍摄，像把手机接到相机旁一起工作。这里选无线选项，才能让像素蛋糕通过热点连接相机。

再查看同一菜单中的「信息」。IP 地址是设备在这个网络里的门牌号，用于找到相机；应显示实际数字。如果只有星号或横线，先排查热点连接，不要把软件里看不到相机直接当作软件故障。[富士连接模式](https://app.fujifilm-dsc.com/zhs/manual/x-s20/connections/network_usb_menu/)、[像素蛋糕连接检查](https://www.pixcakeai.com/guide/170683)

### 第五步：在像素蛋糕接收照片

打开像素蛋糕 →「联机」→「开始检测相机」，选 X-S20 并连接。按钮名称以当前版本为准。进入联机拍摄后选择已有项目或创建新项目，后续照片导入这个项目。

项目就是软件里的一组照片，像为这一批游客建立专用相册；**项目内收到照片，不等于已经导出到 iPhone 自带的「照片」相册**。[iPhone 无线使用说明](https://www.pixcakeai.com/guide/124708)

先拍一张，等它完整导入并打开大图；能查看文件信息时检查格式、尺寸。再试拍五张，确认全部收到，以及等待时间是否符合自己的拍摄节奏。没有这一步反馈，本教程不声称这台设备已经完成无线传图验证。

## 有线连接：相机通过数据线连接 iPhone

像素蛋糕的[支持列表](https://www.pixcakeai.com/guide/32569)列有 X-S20 的手机有线支持。不过，厂商也说明富士与移动设备可能出现只充电、无法识别相机的情况；支持列表不能保证每套手机和线材都成功。建议先用已有线材试接，再决定是否购买专用线。[兼容问题](https://www.pixcakeai.com/guide/176576)

### 第一步：按 iPhone 接口准备线材

| 手机接口 | 连接方式 |
| --- | --- |
| USB-C，iPhone 15 系列及之后机型常见的椭圆形接口 | 支持数据传输的 USB-C 对 USB-C 线：手机 ↔ 相机 |
| Lightning，旧款 iPhone 常见的扁平插头接口 | 支持相机连接的 Lightning 转 USB-A 转接头，再接 USB-A 对 USB-C 数据线到相机 |

USB-A 是常见的较大长方形 USB 插头。旧款 iPhone 的相机转接头像一座接口桥，让手机识别外接相机；不能仅用一根普通充电线替代。有些线只能充电，买线或试线时确认支持数据传输。[官方线材说明](https://www.pixcakeai.com/guide/97407)

### 第二步：改变相机设置

先退出像素蛋糕中的无线联机，拔掉线，然后设置：

1. 「网络/USB设置 → 连接模式 → **USB TETHER自动拍摄**」。这是插线后进入联机、断开后恢复普通拍摄的模式。
2. 「网络/USB设置 → USB供电/设置 → **电源关/通信开**」，部分菜单显示为「电源关闭/通信开启」。这里保留传数据功能、禁止相机从连接设备取电，**不会关闭相机机身电源**；也不能据此保证相机绝不会给手机供电。

不要选「USB网络相机」，那是把相机当作电脑摄像头使用的另一个功能；本次要的是拍摄照片并传到手机。[像素蛋糕富士设置](https://www.pixcakeai.com/guide/170683)、[富士对供电选项的解释](https://app.fujifilm-dsc.com/zhs/manual/x-s20/connections/network_usb_menu/)

### 第三步：插线，在软件中选择项目

相机装着存储卡、开机，用准备好的线连接 iPhone。打开像素蛋糕 →「联机」，允许相机和文件访问。看到相机型号和「已联接」后，点「联机拍摄」并选项目，试拍一张确认导入。

如果没有识别，官方排查建议也包括查看 iPhone 自带「照片」中是否出现相机设备，再检查线材和权限。若始终只充电而没有相机，参见[有线只充电的问答](docs/FAQ.md#有线连接后手机只充电认不出相机怎么办)。本次尚无有线成功实测记录。[iPhone 有线流程](https://www.pixcakeai.com/guide/97407)

## 给游客交付大图的设置

不需要大幅调整原始拍摄数据、主要交付高质量成片时，建议：

**图像尺寸 L＋图像质量 FINE＋格式 JPEG，比例按需要选 3:2 或 16:9。**

JPEG 是手机普遍能打开的成片文件，像已经洗好的照片，方便游客直接使用。L 管照片尺寸，FINE 管压缩程度，两项都要设置。菜单只显示 L/M/S 时选择 L，不要寻找本文早期解释中曾使用的说明书符号 O。

正常未裁切的最大尺寸，3:2 为 6240 × 4160；16:9 为 6240 × 3512。3:2 保留较完整画面，16:9 适合宽屏效果。RAW 是保留较多拍摄原始数据的文件，像底片，主要增加后期调整余地；它不会让相同画面自动获得更多像素。[画质、比例和无损问答](docs/FAQ.md#给游客拍照一定要-raw-吗)、[富士画质说明](https://app.fujifilm-dsc.com/zhs/manual/x-s20/menu_shooting/image_quality_setting/)

## 每次开拍前检查

- 试拍一张并确认接收的是完整文件，能打开大图。
- 确认照片实际保存位置，尤其不要把无线模式的存储卡视为自动备份。
- 确认手机剩余空间、电量，以及连续拍摄时能否收齐照片。
- 交付时使用原尺寸或最高画质导出，检查最终文件；经过聊天软件发送时留意其压缩设置。

这些检查用于确认你的设备组合是否成功；它们不是本次已经完成的实测结果。
